# 학습 체크리스트 — 다른 세션과 주고받는 법

Career OS 의 학습은 **경로 → 단계(주차) → 체크 항목** 이다. 체크 항목은 Claude 세션이
만들고, 기록 · 진행률 · 레벨 규칙은 Career OS 가 맡는다 (DECISIONS 30장).
이 문서는 두 쪽이 같은 형식으로 말하게 하는 약속이다.

---

## 한 바퀴

```
Career OS 학습 단계 화면
  └ "다른 세션에 넘길 프롬프트 복사"
        ↓ (트랙 설명 · 이번 단계 · 마감 · 체크 진행 · 형식)
Claude 세션 — 붙여넣고 "이번 주 체크리스트 만들어줘"
        ↓ HTML 아티팩트 (또는 Markdown)
Career OS — 경로에서 "주차 체크리스트를 붙여넣어 단계 만들기"
            또는 단계 화면 체크리스트 칸 "붙여넣어 가져오기"
        ↓ 미리보기에서 뺄 줄 끄고 저장
하루하루 체크 → 모두 체크하면 완료를 권함 → 회고 · 오늘 계획에 반영
```

프롬프트는 `GET /learning-steps/{id}/handoff` 가 만든다 (`backend/app/services/handoff.py`).
경로 설명이 비어 있으면 세션이 트랙 맥락을 모른다 — **경로 설명에 목표 · 진행 방식 ·
기록 도구를 적어 두는 것** 이 이 흐름의 전제다.

---

## 읽는 형식 (`backend/app/services/checklist_parser.py`)

### HTML 아티팩트

| 요소 | 뜻 |
|---|---|
| `<h1>` (없으면 `<title>`) | 주차 제목 → 새 단계를 만들 때 이름으로 제안 |
| `<h2>` `<h3>` `<h4>` | 묶음 이름 |
| `<li>` | 체크 항목 한 줄. 안의 `<code>` 는 `` `이름` `` 으로 남는다 |
| `<input type="checkbox" checked>` (li 안) | 이미 체크된 항목 |
| `class` 에 `note` 가 들어간 `<p>` `<div>` `<span>` | 묶음 설명 (체크하지 않음) |
| `<a href="https://...">` | 자료 링크. http · https 만 |
| `<script>` `<style>` `<svg>` `<button>` 등 | 읽지 않음 |
| `<table>` | 가져오지 않음 — 할 일이면 목록으로 |

### Markdown · 줄글

| 줄 | 뜻 |
|---|---|
| `# 제목` | 주차 제목 (처음 한 번) |
| `## 묶음` | 묶음 이름 |
| `- [ ] 항목` / `- [x] 항목` | 체크 항목 / 체크된 항목 |
| `- 항목`, `1. 항목`, `☐ 항목` | 체크 항목 |
| `> 설명` | 묶음 설명 |
| `[이름](https://...)` 한 줄, 또는 주소만 한 줄 | 자료 링크 |
| `묶음 이름:` (짧고 콜론으로 끝남) | 묶음 이름 |
| 그 밖의 줄 | 체크 항목 |
| `\| 표 \|` | 가져오지 않고 몇 줄 뺐는지 알림 |

### 한도 · 지키는 것

- 항목 200개, 한 줄 300자, 링크 30개까지.
- 붙여넣은 글만 읽는다. **링크를 열지 않는다.** 미리보기는 저장하지 않는다.
- 아티팩트 화면에서 누른 체크는 파일에 남지 않아 읽을 수 없다 — 체크는 Career OS 에서.
- 모두 체크해도 단계를 저절로 끝내지 않는다. 체크로 레벨이 오르지 않는다.

## 좋은 체크 항목

- **한 번에 끝낼 수 있는 일 하나.** "CLIP 공부" 가 아니라 "`contrastive loss` 수식을 손으로 따라 적기".
- **끝났는지 알 수 있는 말.** "읽기" 보다 "Figure 1 을 한 문단으로 설명해 적기".
- **30~60분 단위.** 오늘 계획이 학습 카드에 다음 항목 세 줄을 보여준다.
- **코드는 이름만.** 코어 알고리즘을 대신 짜 달라고 하지 않는다 — 항목은 할 일이지 정답이 아니다.
- 마감(발표일 · 제출일)은 단계에 넣는다. 14일 안이면 우선순위 1위 스킬이 아니어도 오늘 계획에 오른다.
