# 내 컴퓨터에서 돌리기

데모는 둘러보기만 되는 화면이다. 실제로 쓰려면 내 컴퓨터에서 띄워야 한다.
**데이터는 내 컴퓨터 안에만 있다** — 어디로도 보내지 않고, 만든 사람도 못 본다.

## Docker 로 (권장)

```
git clone https://github.com/nocked115/career-os-portfolio.git career-os
cd career-os
docker build -t career-os .
docker run -p 127.0.0.1:8000:8000 -v career-os-data:/data career-os
```

`http://localhost:8000` 을 연다.

- `docker build` 는 처음 한 번만. 코드를 받아 바꿨으면 다시 한다.
- `-v career-os-data:/data` 가 데이터 창고다. **이게 없으면 컨테이너를
  지울 때 기록도 같이 사라진다.**
- `-p` 앞의 **`127.0.0.1:` 을 빼지 않는다.** 빼면 같은 와이파이의 다른
  기기에서 그대로 열린다. 비밀번호가 없는 것이 기본값이라, 학교나 카페
  네트워크에서는 지나가는 사람이 내 지원 기록을 본다.
- 멈추려면 Ctrl+C.

## Docker 없이

Python 3.13 과 Node 22 가 있으면 된다.

```
bash scripts/local.sh
```

`127.0.0.1` 에만 묶여서 이 컴퓨터 밖에서는 안 열린다.

## 처음 켜면 비어 있다

이 앱은 1인용이고 빈 상태로 시작한다. 순서는 이렇다.

1. **프로필** — 졸업 시점과 가고 싶은 직무를 적는다. 공고 점수가 전부
   여기서 갈린다.
2. **스킬** — 지금 할 줄 아는 것과 수준. 모르면 비워 두어도 된다.
   공고가 쌓이면 앱이 "이 스킬 공고가 몇 건" 으로 먼저 말해 준다.
3. **기회** — 공고를 붙여넣는다. 수집원(고용24 · 사람인)은 API 키가
   있어야 돌아간다. 키 없이도 붙여넣기로 쓸 수 있다.
4. **학습** — 경로와 단계를 만든다. 계획 내용 자체는 AI 가 쓰고, 앱은
   구조 · 진도 · 증거를 갖는다. 학습 화면의 **"다른 세션에 넘길 프롬프트
   복사"** 로 프롬프트를 받아 Claude 에 붙여넣고, 받은 로드맵을 다시
   앱에 가져오면 된다. 앱 안에 AI 는 들어 있지 않다 — 계정도 키도
   연결할 것이 없다.

## 공고 수집을 켜려면

`backend/.env` 에 키를 넣는다. 둘 다 없어도 앱은 돈다.

```
WORK24_API_KEY=...      # 고용24 (work.go.kr) 오픈API
SARAMIN_API_KEY=...     # 사람인 (oapi.saramin.co.kr), 승인 필요
```

자세한 것은 `docs/DEPLOY.md`.
